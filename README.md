# Лабораторная работа: Обработка массивов
## Автор: Мыльников А.М.
## Вариант 19

## Описание:
Программа находит в каждом столбце число отрицательных элементов, и наименьший из отрицательных элементов столбца, а также выводит матрицу в общепринятом виде.

## Ожидаемые результаты
 - Матрица, выведенная в общепринятом виде
 - Число отрицательных элементов в столбце
 - Наименьший из отрицательных элементов
