# Лабораторная работа: Линейные алгоритмы
## Автор: Мыльников А.М.
## Вариант 19

## Описание:
Программа вычисляет ускорение движения бруска в случае, если трение отсутствует

## Исходные данные:
 - Масса клина - M: 25,52 кг
 - Угол альфа - alpha: 40°
 - Масса бруска - m: 5,7 кг
 - Коеффициент трения - k: 0,15

## Ожидаемые результаты
 - a1: Трение отсутствует между клином и горизонтальной плоскостью
 - a2: Трение отсутствует между бруском и клином
