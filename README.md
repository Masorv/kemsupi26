# Лабораторная работа: Цикл с пред- и постусловием
## Автор: Мыльников А.М.
## Вариант 19

## Описание:
Программа вычисляет упругую постоянную металической трубы при различных внутренних диаметрах трубы.

## Исходные данные:
 - E – модуль упругости.
 - μ – коэффициент Пуассона.
 - L – длина трубы.
 - d0, d – наружный и внутренний диаметр трубы.

## Ожидаемые результаты
 - k – упругую постоянную металической трубы при различных внутренних диаметрах трубы.
