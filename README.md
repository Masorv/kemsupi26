## Описание:
Программа вычисляет количество элементов в массивах T и Y, размерами n и k соответственно, больших чем c.

## Исходные данные:
 - c - элемент с которым сравниваем значения других
 - n - размер массива T
 - k - размер массива Y
 - Массив T
 - Массив Y

## Ожидаемые результаты
 - количество элементов больших чем c в массиве T
 - количество элементов больших чем c в массиве Y
