# Лабораторная работа: Структуры и файлы
## Автор: Мыльников А.М.
## Вариант 17

## Описание:
Программа выводит данные о маршруте и средний интервал движение автобусов на нём если количество автобусов на нём меньше указанного значения, тоакже выводит маршрут с наибольшим количеством автобусов на нём.

## Исходные данные:
 - Файл Routes.txt, содержащий данные о маршрутах
 - routeCount - количество маршрутов
 - criteria - значение с которым сравниваем

## Ожидаемые результаты
 - Данные о маршрутах, количество автобусов в которых меньше указанного числа
 - Маршрут с наибольшим количеством автобуса
